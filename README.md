# Smile Dental Care – Clinic Website

A modern, responsive single-page website for **Smile Dental Care**, a dental clinic located at:

**A-123 Ramphal Chowk, Sector 7 Dwarka, Delhi 110077**

## Live site

After enabling GitHub Pages (Settings → Pages → Deploy from branch `main` / root), the site will be available at:

**https://paltarun023-svg.github.io/smile-dental-care/**

## Features

- Clean, professional design with teal accent colour
- Fully responsive (mobile + desktop)
- Sections: Hero, About, Services, Doctors, Reviews, Contact + Map
- Click-to-call and Google Maps directions
- Simple appointment request form (frontend only)
- Mobile-friendly navigation
